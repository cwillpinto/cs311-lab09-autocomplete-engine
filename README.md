# CS311 Lab 9: Autocomplete Engine

Read `Lab_09_Autocomplete_Engine.md` for the 100-point assignment and its October 26, 2026 due date. Check Blackboard Ultra for the exact deadline time.

## Build and check

Use Python 3.11 or newer; no third-party packages are required. Complete the four recursive methods in `test_autocomplete.py` and leave its verification suite intact. Run `python test_autocomplete.py` from the repository root. The starter intentionally raises `NotImplementedError`; a completed implementation should print the handout's success token. The public tests cover only their stated behaviors.

## Work in your own GitHub repository

If the instructor starter is a template, select **Use this template** on GitHub, create a repository under your own account, and clone it locally. For a direct clone, create an empty repository under your account first:

```sh
git clone https://github.com/cwillpinto/cs311-lab09-autocomplete-engine.git
cd cs311-lab09-autocomplete-engine
git remote rename origin upstream
git remote add origin <your-repository-url>
git remote -v
git push -u origin <your-branch>
```

Check that `origin` points to your repository before pushing. Do not push to the instructor repository. Commit your code and copy its full SHA with `git rev-parse HEAD`.

## Submit in Blackboard Ultra

Submit your student-owned repository URL and full commit SHA, `Lab9_Theory.pdf` or `.md` with the requested tables and diagrams and concise explanations, and terminal output or a screenshot showing the success token. Your completed code lives in your repository; a separate code-file upload is not required.
